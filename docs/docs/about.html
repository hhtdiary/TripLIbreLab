About TripLibreLab

TripLibreLab is an open-source companion app to TripLibre, made by HHT Diary. Its tagline sums up the plan: Replay. Simulate. Explore.

The HHT Diary ecosystem

ProjectRole
HHT DiaryThe umbrella organization and wider research and software ecosystem.
TripLibreRecords, organizes and exports travel diary data on iPhone.
TripLibreLabImports, visualises, replays and shares diaries; later, simulates and compares scenarios.

TripLibreLab does not duplicate TripLibre's recording interface and will not become a turn-by-turn navigation app.

Principles

  • User agency. Present choices and trade-offs; never dictate behaviour.
  • Local-first. Process imported diaries on the phone.
  • Privacy by default. No automatic uploading or public sharing; controls to hide sensitive places and times before sharing.
  • Transparent modelling. Keep observed records, replays, synthetic scenarios and model estimates clearly apart.
  • Small, complete releases. Each version is useful on its own.

Open source

The code and these docs are on GitHub at hhtdiary/TripLIbreLab, licensed under the Apache License 2.0. Bug reports, ideas and questions go in GitHub issues.
