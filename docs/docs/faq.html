Using TripLibreLab

FAQ & troubleshooting

Short answers to common questions. If yours isn't here, open an issue on GitHub.

About the app

Can I download TripLibreLab yet?

Not yet. It is in early development. The release status on the homepage will change when there is something to install.

Do I need TripLibre?

Yes. TripLibreLab does not record location itself; it replays diaries that TripLibre recorded. You can install TripLibre now and start building up days to replay later.

Does TripLibreLab replace TripLibre?

No. TripLibre records, corrects and exports your diary. TripLibreLab only reads exports. You keep using TripLibre day to day.

Does it need an account or internet connection?

No account. The core import, replay and share flow is designed to work offline; map tiles may need a connection to load.

Is it free?

Yes, and open source under the Apache 2.0 license.

Will it predict where I'll go or tell me how to travel?

No. The first release only replays what was recorded. Simulation and comparison are planned or exploratory ideas (see the Roadmap), and even then a synthetic day is a model's output under stated assumptions, not a prediction of your behaviour or a recommendation.

Troubleshooting Pending

These answers describe intended behaviour and will be checked against the released app.

The file won't import

Make sure you picked travel.sqlite from a TripLibre export folder, not a CSV or JSON file. If the app reports an unsupported version, update TripLibre and TripLibreLab and export again. See When a file can't be read.

A day I expected is missing

Only days with travel records are listed. If TripLibre didn't record on that day, or the data is in a newer export, make a fresh export.

A trip is a straight dashed line

That trip has no recorded route points, only a start and end, so it is drawn as a schematic line. It shows that a trip happened, not the path. See Recorded points and animated movement.

Part of a route is dashed

GPS was silent for more than 15 minutes during that trip, so TripLibre marked it as having a gap and joined the two sides with a straight line. TripLibreLab draws that connector dashed so it is not mistaken for a measured path.

Which TripLibre versions are supported?

Exports with database schema versions 1 to 6, which covers every TripLibre release up to 2.1.0. A newer export imports with a notice. See Supported versions.

A trip has the wrong mode or place name

TripLibreLab shows the diary as exported. Fix it in TripLibre, then export and import again.
