What TripLibreLab is

TripLibreLab is a companion app to TripLibre, in development for iOS. TripLibre records where you go and keeps it as a travel diary: the visits, trips and travel modes of each day. TripLibreLab takes a diary you export from TripLibre and turns it into something you can watch again, explore and share.

It is a separate app, not a new version of TripLibre. It records no location, needs no account, and works with a copy of your data that you choose to give it.

TripLibreLab is not released yet. These docs describe the first release as it is being built. Anything not yet built and tested is marked Pending, and there are no screenshots until the real interface exists.

The first release at a glance

ImportOpen a TripLibre SQLite export from the Files app. Read-only; the original is never changed.
Pick a daySee which days have travel records, and how many trips each one has.
ReplayWatch the day's trips and stops in order on a map, with play, pause and a scrubber.
SharePreview a summary image, hide sensitive places and times, then share it yourself.

Words used in these docs

TermMeaning
Travel diaryA day-by-day record of where you stayed and how you travelled between places. TripLibre builds one automatically from your phone's location.
Trip and stayA trip is a movement from one place to another; a stay (or stop, or visit) is time spent in one place.
SQLiteA common file format for a small database: a single file with tables in it. TripLibre's export includes one.
ReplayPlaying a recorded day back as an animation on a map.
SyntheticGenerated by a model rather than recorded. Used only in planned future features, and always labelled.
Agent-based simulationA model in which simulated travellers follow simple rules and a day of travel emerges from them. Planned for Phase 2.
