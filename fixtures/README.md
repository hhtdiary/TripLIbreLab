# Test fixtures

Synthetic `travel.sqlite` files for TripLibreLab's importer tests. **No real person's data.** Places are public
Philadelphia landmarks; every time, route and GPS fix is generated by `tools/make_fixtures.py` from TripLibre's
verbatim migration SQL (`tools/triplibre_schema.sql`), then written with `VACUUM INTO` the way TripLibre exports.

| File | Purpose (Step D test) |
| --- | --- |
| `travel-sample.sqlite` | valid sample: one day, 6 trips, 7 stays, all geometry levels, midnight crossing, deleted trip, merged place |
| `travel-no-gps.sqlite` | missing GPS: same day without raw points or polylines |
| `travel-empty.sqlite` | empty diary |
| `travel-v1.sqlite` | oldest supported schema (v1) |
| `travel-future-schema.sqlite` | `user_version = 99`, newer than TripLibreLab knows |
| `not-triplibre.sqlite` | valid SQLite, wrong tables |
| `not-sqlite.sqlite` | malformed file |

Regenerate with `python3 tools/make_fixtures.py` (deterministic content; the SQLite version stamped in the file header may differ between machines, so CI compares content, not bytes). Check any file, including a real export, with
`python3 tools/inspect_export.py <file>`. Field definitions: `docs/sqlite-data-contract.md`.
